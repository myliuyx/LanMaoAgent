## 1. 系统概览

登录后进入控制台页面，显示系统整体状态：

- **数据规模**：股票数量、日线记录数、技术指标数
- **任务状态**：当前运行中的 ETL 任务、任务统计
- **交易日信息**：当前交易日、数据更新状态
- **近期登录用户**：系统访问情况

### 定时任务说明

> 详细配置见 [定时任务使用文档](../stock-fast-api/docs/定时任务使用文档.md)

系统在工作日收盘后自动执行以下任务：

| 时间 | 任务 | 说明 |
|------|------|------|
| 18:00 | 股票主数据同步 | 更新股票列表（代码、名称、行业等） |
| 19:00 | 日线数据同步 | 同步当日行情（开盘、收盘、成交量等） |
| 20:30 | 技术指标计算 | 计算 MA、RSI、MACD、ATR 等指标 |
| 21:30 | 选股宽表构建 | 生成当日选股特征数据 |

> 详细定时任务配置见 [定时任务使用文档](../stock-fast-api/docs/定时任务使用文档.md)

## 2. 选股功能

入口：**选股工作台** (`/selection`)

### 筛选条件

系统支持多维度筛选：

#### 技术指标筛选

| 指标 | 说明 |
|------|------|
| 均线多头 | 5/10/20/60 日均线多头排列 |
| 放量上涨 | 成交量放大且价格上涨 |
| 突破新高 | 突破 N 日最高价 |
| RSI 超买/超卖 | RSI(6) > 70 或 RSI(6) < 30 |
| MACD 金叉/死叉 | DIF 上穿/下穿 DEA |
| N 日涨幅 | 近 N 日涨幅超过 X% |
| 趋势评分 | 综合趋势评分高于 X 分 |

#### 财务指标筛选

| 指标 | 说明 |
|------|------|
| 市盈率 (PE) | PE(TTM) 在合理范围 |
| 市净率 (PB) | PB 在合理范围 |
| 净资产收益率 (ROE) | 净利润/净资产 |
| 营收增长率 | 营收同比增长率 |
| 净利润增长率 | 净利润同比增长率 |

#### 市场条件筛选

| 条件 | 说明 |
|------|------|
| 交易所 | 上交所 / 深交所 / 北交所 |
| 板块 | 所属行业板块 |
| 市值范围 | 流通市值区间 |
| 涨跌幅 | 当日涨跌幅区间 |
| 停牌状态 | 正常交易 / 停牌 |

### 筛选步骤

1. 选择 **交易日**（默认最近交易日）
2. 设置 **技术指标** 条件
3. 设置 **财务指标** 条件
4. 设置 **市场条件** 筛选
5. 点击 **开始选股**
6. 查看结果，支持分页浏览和导出

### 结果展示

筛选结果以表格展示，包含：
- 股票代码、名称、交易所
- 最新价、涨跌幅、换手率
- 均线状态、RSI、MACD
- 市盈率、市净率、ROE

支持按任意字段排序。

## 3. 个股分析

入口：**搜索股票** 或点击选股结果中的股票代码

### 个股详情页面 (`/stocks/:symbol`)

#### K 线图

使用 TradingView lightweight-charts 渲染专业 K 线图：
- 支持日线、周线、月线切换
- 叠加均线（MA5/10/20/60/120/250）
- 叠加成交量柱状图
- 支持缩放和平移

#### 技术指标

展示各类技术指标数据：
- **均线系统**：MA5/10/20/60/120/250
- **RSI**：RSI(6)、RSI(14)
- **MACD**：DIF、DEA、MACD 柱状图
- **ATR**：真实波幅
- **新高/新低**：突破 N 日新高/新低标记

#### 基本面数据

- **股票资料**：代码、名称、交易所、行业、总股本、流通股本
- **财务指标**：市盈率、市净率、市销率、ROE、营收、净利润
- **估值分析**：历史 PE/PB 分位

#### 所属板块

该股票所属的行业板块和概念板块，点击可跳转板块详情。

## 4. 板块分析

入口：**板块列表** (`/boards`)

### 板块列表

展示所有板块及其统计信息：
- 板块名称、成分股数量
- 板块平均涨跌幅
- 板块总市值

支持按涨跌幅、成分股数量排序筛选。

### 板块详情 (`/boards/:boardCode`)

点击板块进入详情页：
- **板块 K 线**：板块整体 K 线走势
- **成分股列表**：该板块所有成分股
- **个股跳转**：点击成分股进入个股详情

## 5. ETL 任务管理

入口：**任务管理** (`/jobs`)

### 任务列表

展示所有 ETL 任务的执行记录：
- 任务名称、状态（成功/失败/运行中）
- 开始时间、结束时间、耗时
- 处理记录数、错误信息

### 手动触发

支持手动触发以下任务：

| 任务 | 说明 |
|------|------|
| 日线数据同步 | 立即同步当日行情数据 |
| 财务指标同步 | 立即同步财务数据 |
| 技术因子计算 | 立即重新计算技术指标 |
| 选股宽表构建 | 立即重新生成选股宽表 |

### 任务详情

点击任务查看详情：
- 任务配置参数
- 执行日志
- 错误详情（如有）

### 取消任务

运行中的任务支持手动取消。

## 6. 数据回补

入口：**数据回补** (`/backfill`)

当发现某些股票历史数据缺失时，可使用回补功能：

1. 输入股票代码
2. 选择回补的起止日期范围
3. 选择数据类型（日线/技术因子/财务指标）
4. 点击 **开始回补**
5. 查看回补状态和结果

## 7. 自选股管理

入口：**自选股** (`/watchlist`)

### 添加自选股

在个股详情页面点击 **加入自选**，或通过搜索添加。

### 自选股列表

- 展示所有自选股及其最新行情
- 支持分组管理
- 支持删除

### 自选股分析

点击自选股进入个股详情页进行详细分析。

## 8. 数据覆盖查看

入口：**数据覆盖** (`/coverage`)

### 覆盖概览

查看各股票历史数据的完整度：
- 哪些股票缺少哪些日期的数据
- 数据缺失的时间范围
- 可用于判断是否需要回补

### 覆盖详情

点击具体股票查看详细的数据覆盖情况。

## 常见问题

### Q: 任务失败怎么办？

1. 进入任务详情查看错误日志
2. 根据错误信息排查问题（如数据源问题、网络问题）
3. 修复后重新触发任务

### Q: 数据不同步怎么办？

1. 确认当前是否为交易日（工作日 9:30-15:00）
2. 检查 ETL 任务是否正常运行
3. 手动触发数据同步任务

### Q: 如何回补单只股票的历史数据？

使用 **数据回补** 功能，输入股票代码和日期范围即可。
